## Notes for the fix wave

- The three criticals share one root cause: `toolsPage()` (index.html) dropped the generic `#toolsec` mount that plugins.js:210 and two feature files still target. One mount fix resolves B2 and B3; B1 must be fixed in the same wave or the first mounted warning is unreadable.
- One owner per file: the mount fix belongs to the index.html owner; the colour, Enter-handler, sort-order and bar fixes belong to the autopilot.js/schedule.js/grid.js owners.
- After any JS edit: `node --check`, escape through `esc(...)`, no `!important`, no shadows, and `tests/test_feat_files.py` plus `tests/test_text_ink.py` must still pass.
